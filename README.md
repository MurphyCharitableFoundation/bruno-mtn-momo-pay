# MTN Momo Pay API Collection

## Overview
Use this collection as a guide for understanding and interacting with MTN for facilitating mobile money transactions. 

There are two products from MTN fit to support the mobile money service needs of both projects:
- MTN Collection Product
- MTN Disbursement Product

## How to Use this Guide
1. Download Bruno.
   
   [Bruno Github](https://github.com/usebruno/bruno)

2. Clone this repo.

	`git clone git@github.com:MurphyCharitableFoundation/bruno-mtn-momo-pay.git`

3. Open Bruno.

4. Open Collection.

	Navigate to the repository and select the following collections:
    collection and disbursement, one at a time.

5. Register for an MTN Developer account.

	Read the MTN Momo API Docs and replace the variables in your Bruno
    collections with your own (e.g your own subscription-key for each
    product)

## Variables
Ensure to use the correct variables which you can get by perusing the MTN Momo Pay Docs and registering for a developer account. As it stands, the variables used in this collection are associated with a maintainers MTN Developer account.
